How to Edit Events

1. Go to GitHub → your repository.

2. Open index.html.

3. Scroll to the section marked:

>> EDIT EVENTS BELOW <<<

4. Each event looks like:

{ date: "2027-04-17", title: "Regatta", location: "Grafham", class: "F18", notes: "" }

5. To add an event:

  • Copy an event line
  • Paste below
  • Change date/title/location/class

6. Save the file → GitHub Pages updates automatically.

Multi‑Day Events

Use start and end dates:

{ start: "2027-06-17", end: "2027-06-19", title: "Nationals", ... }
